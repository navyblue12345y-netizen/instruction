## Критические уроки дня

### MAX API
- Загрузка фото: POST /uploads?type=image → multipart поле "data" → токен в photos.*.token
- Загрузка видео: POST /uploads?type=video → multipart поле "data" → токен напрямую в response
- chat_id передаётся как query-параметр: POST /messages?chat_id=...
- Видео требует времени на обработку → retry 3 раза с паузой 5 сек (attachment.not.ready)
- 503 Service Unavailable — временные сбои MAX, retry

### Telegram парсинг
- Ссылки cdn4.telesco.pe живут МИНУТЫ — скачивать медиа сразу в telegram.py
- Медиа сохраняется в media/cache/ по MD5-хэшу URL
- Инвайт-ссылки t.me/+ нужно удалять из текста при парсинге
- Хвосты "Вязалочка • Подписаться" убираются regex

### Groq
- Free tier: 100k токенов/день — легко исчерпать при тестировании
- В рабочем режиме (24 поста/день × 200 токенов) = ~5k токенов/день — хватает
- При лимите: использовать _basic_clean() без AI
- Лимиты сбрасываются в 00:00 UTC (03:00 МСК)

### Общая архитектура
- fetcher.py: парсинг TG → скачивание медиа → фильтрация → сохранение в БД
- scheduler.py: каждые 2 часа берёт пост из pending → публикует → mark_posted
- _pick_post(): приоритет фото, каждый 3-й пост видео, проверка дублей по тексту
- seen_posts: дедупликация по URL — не трогать без причины

### Фильтры (processor/filter.py)
- Реклама, мужской контент, сезонность (не по сезону), английский текст, маты
- Сейчас март 2026 (весна) — зимние/осенние/новогодние посты отклоняются
